v1.9.1

2026-10-16

Added

  1. Restore every workspace tab, its order, selected tab, split conversation, zoom and reading position from an encrypted local session. PDF tools now offer four editable presets, an anchored color panel, red default annotation icons and more spacious controls.

Fixed

  1. Drag PDF tools with the pointer, then ease onto the document viewport edges or return to top center when dropped away from an edge. Keep left docking beside the PDF, clear of thumbnails. Drag across text to highlight it. Select notes with a click or marquee and delete only the selection. Confirm before clearing all added or original notes. Collapsing slides the handle to the nearest corresponding document corner. Centered tool icons use one soft selection surface. Undo and redo support Ctrl+Z, Ctrl+Y and Ctrl+Shift+Z.

v1.8.48

2026-10-15

Added

  1. Center the PDF ribbon on each docked edge, use one column on the sides, rotate only the six-dot grip, and animate moving and unfolding. Right-click the grip to fold or expand; the folded grip can move freely and expands on click. Add six editable circular color presets and a custom color wheel. Tool sizes and styles live in right-click settings.

Fixed

  1. Use uniform neutral icons with active backgrounds and custom tool colors, simplify the boxed T and highlighter, fill and soften the inset arrow head, and remove its former width cap. Remove triangle and diamond tools and persistent tips. Top docking follows a collapsed PDF toolbar. Text mode edits existing boxes, and cached page groups track native viewport changes for smoother synchronized scrolling. Match the current page, slash and total page count colors in both themes. Place schedule completion checkboxes on the left, check completed or elapsed events automatically without refreshing Overview, and use a trash icon for removal.

v1.8.47

2026-10-15

Added

  1. The native Draw button toggles a compact icon ribbon with selected-state colors. Drag it to dock at any edge; tools reflow while icons remain upright. Add transparent inline text with a gray dashed editing outline. Symbols stay fixed and can be erased by clicking or dragging; text remains editable. Highlight selected PDF text with the highlighter beside the pen, scroll while editing, save all notes, or exit with the final ×.

Fixed

  1. Right-click drawing tools for individual colors, line widths, text size, rectangle corners, highlighter opacity, and eraser range. Arrows use an inset kite head capped at 3× the shaft width. Add new-tab shortcuts beside Open file and after the final tab; the right-side action is labeled New tab, and the address field is 30% narrower.

Fixed

  1. Restore accurate drawing color swatches in light and dark themes, retain each annotation as a separate PDF object, and rename the schedule reset button to Current.
